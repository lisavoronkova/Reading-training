# Оля и Зоя читают

Семейная игра, в которой Оля и Зоя учатся читать по складам (методика складового чтения Н. А. Зайцева) и за правильные ответы кормят своего друга: Зоя — радужного котика-единорога, Оля — любую картинку, которую загрузят родители.

- **Проверка в начале:** Зоя показывает знакомые буквы, Оля читает вслух склады и слова; игра сама решает, с чего начать.
- **Четыре игры:** «Шарики» (послушай и лопни склад), «Слоги» (прочитай склад и найди картинку), «Формы слов» (прочитай слово), «Паровозик» (собери слово из складов), плюс 22 темы и таблица складов.
- **Прогресс видно:** карта-дорожка, угощения за уровень, звёзды, подарки с наклейками, альбом, гардероб с нарядами за звёзды, солнышки дней подряд.
- **Звуки:** все эффекты и музыкальная шкатулка синтезируются в браузере.
- **Сложность подстраивается:** 2–4 картинки или шарика в зависимости от успехов.
- Без оплаты, регистрации и рекламы. Работает без интернета, прогресс можно сохранить в файл.

## Где играть, чтобы прогресс не пропадал

### Вариант 1. GitHub Pages — без входа в аккаунт

Когда репозиторий станет публичным:

1. На GitHub откройте репозиторий → **Settings** → **Pages**.
2. **Source:** Deploy from a branch. **Branch:** `claude/reading-game-tz-z4520h`, папка `/ (root)` → **Save**.
3. Через минуту-две игра откроется по адресу **https://lisavoronkova.github.io/Reading-training/**.
4. На планшете откройте этот адрес и установите игру на главный экран: в Safari — «Поделиться» → «На экран „Домой“», в Chrome — меню → «Добавить на главный экран».

Как здесь хранится прогресс:
- в памяти браузера на этом устройстве; у установленной на главный экран игры браузер её не стирает сам;
- игра работает и без интернета;
- на другом планшете прогресс будет свой;
- для подстраховки: раздел для родителей → «Настройки» → «Резервная копия» → «Сохранить копию в файл». Из этого же файла прогресс восстанавливается на любом устройстве.

### Вариант 2. Ссылка на claude.ai — общий прогресс на всех устройствах

Прогресс хранится в базе опубликованной страницы, в личном разделе вашего аккаунта: не пропадает при очистке браузера и одинаковый на всех устройствах, где открыта ссылка под вашим аккаунтом. На планшете нужно войти в claude.ai.

Где сейчас хранится прогресс, видно в разделе для родителей → «Настройки» → «Сохранение прогресса».

Запуск на компьютере для разработки:

```bash
python3 -m http.server 8000
# затем http://localhost:8000
```

Если склады не звучат, установите русский голос: на iPhone/iPad — Настройки → Универсальный доступ → Устно → Голоса → Русский; на Android — Настройки → Синтез речи → Google → русский язык.

## Как устроено

| Файл | Что внутри |
|---|---|
| `js/sklady.js` | Разбивка на склады, ударение, формы слов, цвета, таблица складов |
| `js/words.js` | Словарь: темы, слова, картинки-эмодзи, похожие слова |
| `js/levels.js` | Уровни всех игр и подбор заданий |
| `js/audio.js` | Синтез речи, звуковые эффекты, музыкальная шкатулка |
| `js/characters.js` | Персонажи, наряды, свои картинки |
| `js/store.js` | Сохранение прогресса и настроек в браузере |
| `js/cloud.js` | Облачное сохранение на claude.ai |
| `js/core.js` | Ядро: данные, навигация, награды, персонаж |
| `js/screen-home.js` | Выбор девочки, карта-дорожка, темы |
| `js/screen-play.js` | «Картинки», «Шарики», «Паровозик», итог уровня и подарки |
| `js/screen-check.js` | Проверка «Что я уже умею» |
| `js/screen-extras.js` | Таблица складов, кладовая, альбом, гардероб |
| `js/screen-parents.js` | Раздел для родителей |
| `css/game.css` | Оформление |
| `sw.js`, `manifest.webmanifest`, `icons/` | Установка на главный экран и работа без интернета |
| `artifact.html` | Та же игра для публикации на claude.ai |

Новое слово добавляется одной строкой в `js/words.js`: `['маш+ина', '🚗']`, где `+` стоит перед ударной гласной. Затем запустите тесты:

```bash
node --test
```
