# Оля и Зоя читают

Семейная игра, в которой Оля и Зоя учатся читать по складам (методика складового чтения Н. А. Зайцева). Девочки читают склады и слова, находят нужную картинку и за правильные ответы кормят своего друга: Зоя — радужного котика-единорога, Оля — любую картинку, которую загрузят родители (например, фото её игрушки).

- Три раздела: «Слоги» (10 уровней), «Формы слов» (11), «Слова по темам» (22 темы, 318 слов).
- Таблица складов, кладовая с угощениями, раздел для родителей с прогрессом и настройками.
- Склады и слова читает синтез речи устройства, записывать ничего не нужно.
- Без оплаты, регистрации и рекламы. Прогресс хранится только на устройстве.

## Как запустить

Откройте `index.html` в браузере: на компьютере двойным щелчком или через любой статический сервер.

```bash
python3 -m http.server 8000
# затем http://localhost:8000
```

Чтобы играть на планшете, страницу нужно где-то разместить, например на GitHub Pages: Settings → Pages → Deploy from a branch → корень ветки.

Если склады не звучат, установите русский голос: на iPhone/iPad — Настройки → Универсальный доступ → Устно → Голоса → Русский; на Android — Настройки → Синтез речи → Google → русский язык.

## Как устроено

| Файл | Что внутри |
|---|---|
| `js/sklady.js` | Разбивка на склады, ударение, формы слов, цвета |
| `js/words.js` | Словарь: темы, слова, картинки-эмодзи, похожие слова |
| `js/levels.js` | Уровни и подбор заданий |
| `js/audio.js` | Синтез речи и звуки |
| `js/characters.js` | Персонажи |
| `js/store.js` | Сохранение прогресса и настроек |
| `js/app.js` | Экраны и игровой процесс |
| `css/game.css` | Оформление |
| `artifact.html` | Та же игра для публикации на claude.ai |

Новое слово добавляется одной строкой в `js/words.js`: `['маш+ина', '🚗']`, где `+` стоит перед ударной гласной. Затем запустите тесты:

```bash
node --test
```
